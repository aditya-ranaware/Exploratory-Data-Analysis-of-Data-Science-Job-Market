# Exploratory Data Analysis of Data Science Job Market

## Project Overview
This project performs **Exploratory Data Analysis (EDA)** on a dataset related to data science jobs.  
The goal of the project is to analyze **salary trends, experience levels, company sizes, job roles, and remote work patterns** in the data science industry.

---

## Tools & Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

---

## Dataset Features
The dataset contains the following columns:

- Job Title  
- Experience Level  
- Company Size  
- Company Location  
- Employment Type  
- Remote Ratio  
- Years of Experience  
- Salary (USD)

---

## Analysis Performed
- Data loading and exploration
- Handling missing values
- Removing duplicate records
- Univariate analysis
- Bivariate analysis
- Data visualization

---

## Key Insights
- Salary increases with experience.
- Senior-level roles have higher salaries.
- Large companies tend to offer better salary packages.
- Remote and hybrid work options are common in data science jobs.

---

## Conclusion
This project demonstrates how **Exploratory Data Analysis (EDA)** can be used to understand patterns and trends in the **data science job market** using Python.
